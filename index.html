Installer Hermes chez vous

Votre ordinateur. Votre compte ChatGPT Plus. Six étapes.

ÉTAPE 1 / 6

Ouvrez ChatGPT

Sur votre ordinateur, installez l’application officielle ChatGPT. Ouvrez-la et connectez-vous avec votre compte Plus.

Repère · L’application est ouverte, pas seulement un onglet Internet.

ÉTAPE 2 / 6

Passez en mode local

Menu ChatGPT → Codex → New chat.
Dans Work in, choisissez This computer / Local.
Créez le dossier Documents / Hermes-atelier et ouvrez-le dans Codex.

Créer le dossier de travail

Explorateur de fichiers → Documents → Nouveau dossier.Finder → Documents → Fichier → Nouveau dossier. Nommez-le Hermes-atelier, puis ouvrez-le comme dossier de travail dans Codex.

Les noms des boutons peuvent varier. Si Local est absent, appelez le formateur. Aucun compte GitHub à créer.

Repère · Codex travaille sur votre ordinateur. Ni Cloud, ni Worktree.

ÉTAPE 3 / 6

Confiez l’installation à Codex

Copiez la demande, collez-la dans le message Codex, puis envoyez-la. Codex installe Hermes dans son terminal local et contrôle le résultat.

Mac : menu Apple → À propos de ce Mac. Ce parcours vise M1 ou suivant. Si « Intel » apparaît, appelez le formateur.

Comment savoir si l’installation est faite ?

Codex contrôle le lancement de hermes et hermes doctor. Il distingue installation présente, configuration du compte à faire et véritable erreur. Ne relancez pas le script si Hermes est déjà installé.

Repère · Lisez les autorisations expliquées par Codex. Si une demande est incompréhensible, appelez le formateur.

ÉTAPE 4 / 6

Reliez votre compte Plus

Démarrer → tapez PowerShell → Ouvrir.⌘ + Espace → tapez Terminal → Entrée. C’est la fenêtre où écrire les commandes.

hermes model
  1. Collez la commande dans le terminal, puis Entrée.
  2. Flèches + Entrée : ChatGPT or Codex Subscription.
  3. Ouvrez le lien affiché. Sur la page officielle OpenAI, connectez le même compte Plus et saisissez le code.
  4. Revenez au terminal. Choisissez un modèle proposé.
Un blocage ou un choix différent ?

Fermez puis rouvrez le terminal si la commande est introuvable. Si l’option manque, si le code est refusé ou si une limite apparaît, appelez le formateur. Ne choisissez ni OpenAI API ni Nous Portal ; n’achetez rien.

Ne partagez ni mot de passe ni code dans une conversation. Plus inclut Codex avec des limites variables ; la documentation ne garantit ni l’éligibilité de chaque compte dans Hermes, ni ses quotas. Les connexions ChatGPT et Hermes sont distinctes.

Repère · Le fournisseur et le modèle sont enregistrés. Le premier essai reste à faire.

ÉTAPE 5 / 6

Essayez votre agent

Dans le terminal, tapez hermes, puis Entrée. Collez ensuite cette demande dans la conversation Hermes.

Réponds en français. Je suis artisan menuisier. Pose-moi trois questions pour préparer un devis de rangement sur mesure. N’invente pas de prix et n’envoie rien.

Une erreur ? Notez-la et appelez le formateur. Installé sur votre ordinateur ne veut pas dire hors ligne : le modèle répond par Internet.

Repère · Le modèle est affiché et répond sans erreur. Demandez ensuite : « Reformule la première question plus simplement. »

ÉTAPE 6 / 6

Retrouvez-le demain

Pour quitter la conversation : /quit, puis Entrée.
Demain, ouvrez PowerShellTerminal et lancez Hermes.

hermes

Pour reprendre la dernière conversation :

hermes --continue
Demander de l’aide à Codex

Indiquez l’étape et le message d’erreur, sans code de connexion, mot de passe ni donnée sensible. Si Codex propose un achat, une clé API ou Cloud, arrêtez-vous et appelez le formateur.

Repère · Vous savez ouvrir votre agent sans refaire l’installation.

Installation locale assistée par Codex · Windows ou Mac Apple Silicon · Compte ChatGPT Plus

1

Ouvrir ChatGPT

2

Choisir Codex Local

Menu ChatGPT → Codex → New chat → Work in → This computer / Local. Créez Documents / Hermes-atelier et ouvrez ce dossier dans Codex. Ni Cloud, ni Worktree.

3

Demander l’installation

Dans le guide HTML : choisissez Windows ou Mac → Copier la demande → collez-la dans Codex. Il utilise le script officiel stable, sans configuration automatique, puis contrôle hermes doctor. Ne réinstallez pas un Hermes existant.

4

Connecter le compte

Ouvrez PowerShell (Démarrer) ou Terminal (⌘ + Espace). Tapez hermes model → Entrée → flèches → ChatGPT or Codex Subscription. Ouvrez le lien, connectez le compte Plus et saisissez le code sur la page OpenAI. Revenez au terminal, choisissez un modèle.

5

Faire deux essais

Tapez hermes. Demandez : « Je suis menuisier. Pose-moi trois questions pour préparer un devis de rangement sur mesure. N’invente pas de prix et n’envoie rien. » Puis : « Reformule la première question plus simplement. » Le modèle doit répondre sans erreur.

6

Revenir demain

/quit pour quitter. Rouvrez votre terminal et tapez hermes pour une nouvelle conversation, ou hermes --continue pour reprendre la dernière.

Un blocage ? Appelez le formateur. N’achetez rien, ne choisissez pas Cloud ou OpenAI API. Ne partagez ni mot de passe ni code. Mac Intel : parcours à examiner avec le formateur.
